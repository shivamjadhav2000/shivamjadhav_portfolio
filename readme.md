# Shivam Jadhav's Portfolio

Welcome to the source code repository for [Shivam Jadhav's Portfolio](https://shivamjadhav.com). This website showcases my projects, experience, skills, and blog posts, and is built using HTML, CSS, and JavaScript.

## Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive Sections:** Includes About Me, Experience, Projects, Skills, Blog, and Contact.
- **Integrated Services:** Features LinkedIn badges, GitHub, Medium links, and more.
- **Dynamic Carousel:** Rotates through featured images.
- **Easy Navigation:** Clean layout with intuitive navigation.

## Technologies Used

- **HTML5** for semantic structure.
- **CSS3** for styling and responsive design.
- **JavaScript** for interactivity and dynamic content.
- External resources including [Google Fonts](https://fonts.google.com/) and [FontAwesome](https://fontawesome.com/) for icons.
