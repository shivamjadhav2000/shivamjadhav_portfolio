About the Project

The Universal Digital Signage web application provides a centralized solution for managing content across multiple digital signs. Users can upload images, create playlists, and assign them to signs individually or in groups. Features include scheduled playlist changes, interrupt scheduling, and interactive kiosk modes—helping organizations reduce costs and improve engagement.
